Import content

Load objective files, exam files, and exam PDFs that Claude generates in the MedVault format. Importing merges by id — re-importing an updated file overwrites the old one and keeps your progress. PDFs are stored offline so you can study from them anytime.

Backup & reset

Your data (content + all progress) lives in this browser. Export a single backup file to move it or keep it safe.

File format for Claude

Hand this schema to Claude when converting your existing objectives and exams. Questions link to objectives through their los array; objectives carry a week so everything groups automatically.

CNS_SBA_Exam.key.json  ·  PDF-anchored method (recommended)

            
Put the exam PDF in your data/ folder next to a small key like this. MedVault reads the paper itself — you study straight from the PDF, figures and all — so the key only needs each question's answer and los, matched by n. The pdf field must equal the PDF's filename.
